지금타 V11 — 배포 준비 버전

주요 개선
1) 출발시각
- 정확한 시각 입력
- 지금 / +5 / +10 / +15 / +20 / +30분 빠른 선택
- 기본값은 현재시각 +10분

2) 즐겨찾기
- 현재 경로와 환승시간, 운행일을 브라우저 localStorage에 저장
- 즐겨찾기 이름 지정 / 불러오기 / 삭제
- 출발시각은 매번 달라지는 값이라 저장하지 않음

3) UI
- 개발용 프리셋 제거
- 실제 서비스형 경로 빌더 / 결과 화면으로 정리
- 1~9호선 노선 색상 표시
- 모바일 반응형 개선
- 오류/로딩/신뢰도 표시 단순화

4) 배포
- 환경변수 SEOUL_API_KEY 지원
- 환경변수 PORT가 있으면 0.0.0.0:$PORT 로 실행
- 로컬에서는 기존처럼 API 키를 콘솔에서 입력
- Procfile 포함
- 외부 Python 패키지 없음

로컬 실행
1. 압축 해제
2. run.bat
3. 서울 열린데이터광장 API 키 입력
4. 브라우저 자동 실행

배포 시 필수 환경변수
SEOUL_API_KEY=<서울 열린데이터광장 인증키>

서버 시작 명령
python app.py

주의
- 현재 즐겨찾기는 브라우저 localStorage 기반이므로 다른 기기/브라우저와 동기화되지 않습니다.
- 사용자 계정 기반 즐겨찾기가 필요해지면 Supabase 등 DB를 붙이는 다음 단계가 필요합니다.
- 공휴일 자동 판정은 아직 요일 기반이므로 평일 공휴일은 '일요일·공휴일'을 직접 선택해야 합니다.


V7 — 이동 중 라이브 열차 추적
- 경로 계산 결과의 각 구간에 '이 열차 탑승' 버튼 추가
- 버튼을 누르면 해당 열차번호를 현재 구간에 잠금
- 20초마다 realtimePosition으로 그 열차만 계속 추적
- 탑승 열차의 최신 환승역 ETA를 seed로 이후 모든 구간을 다시 계산
- 다음 구간이 처음에는 시간표+현재 지연 추정(중간 신뢰도)이더라도,
  실제 후보열차가 realtimePosition에 나타나면 자동으로 높은 신뢰도로 전환
- 다음 추천열차가 바뀌거나 신뢰도가 높음으로 전환되면 화면 알림
- 환승 후 다음 열차의 '이 열차 탑승'을 누르면 추적 대상을 새 열차로 전환
- 현재 라이브 추적 상태는 sessionStorage에 저장되어 같은 탭 세션의 새로고침에도 복원
- '추적 종료' 버튼 제공

API
POST /api/trip_update
  active_index
  boarded_train_no
  boarded_at
  segments
  day

주의
- 실시간 위치 API가 특정 열차를 잠시 누락해도 열차 잠금은 유지합니다.
  이때는 공식 시간표 + 현재 동일 방향/등급 지연값으로 임시 계산하며 신뢰도 '중간'으로 표시합니다.


V8 — 시발역/출발 직후 미포착 열차 대응
- 각 구간에서 실시간 후보 + 공식 시간표 후보를 동시에 구성
- 승차 준비시각 기준 약 60분 이내 열차를 최대 6개 '근처 열차 후보'로 표시
- 후보 표시:
  · 실시간 확인
  · 시간표 후보 · 미포착
- 동일 열차번호가 realtimePosition에 등장하면 실시간 후보가 자동 우선
- 미포착 후보에서도 실제 탑승 후 '탑승' 버튼 사용 가능
- 탑승 시 열차번호 고정 후 V7의 20초 라이브 추적 시작
- realtimePosition에 이후 포착되면 신뢰도 중간 → 높음 자동 전환

핵심 원칙
'실시간에 안 보인다 = 열차가 없다'가 아니다.
공식 시간표를 열차 존재 후보로 사용하고, realtimePosition을 실시간 운행 확인 신호로 사용한다.

V9.1 — 탑승시각 UTC/KST 오류 수정

원인
- 프론트엔드에서 탑승시각을 new Date().toISOString()으로 저장
- toISOString()은 UTC이므로 한국 로컬시각보다 9시간 느린 값이 백엔드에 전달됨
- 도착 ETA는 로컬시각으로 계산되어 '차내 이동시간'만 약 9시간 크게 표시됨

수정
- 탑승시각을 브라우저의 로컬 년/월/일/시/분/초로 직접 직렬화
- 기존 sessionStorage의 잘못된 boardedAt을 복원하지 않도록 TRIP_KEY 버전 갱신
- 도착 ETA 계산 로직과 시간표 데이터는 변경하지 않음

예
- 실제 탑승 15:00
- 기존 저장값 06:00 (UTC) -> 잘못된 차내시간 약 +9시간
- 수정 저장값 15:00 (KST/local) -> 정상


V11 — 대한민국 공휴일/대체공휴일 자동 운행일 + 급행 표시 강화

AUTO 운행일
- 일반 평일 -> DAY
- 일반 토요일 -> SAT
- 일요일 -> END
- 법정 공휴일 -> END
- 대체공휴일 -> END
- 2026~2035 공휴일 달력을 앱에 번들하여 런타임 외부 API 없이 판정
- 설날/추석/부처님오신날의 음력 날짜도 포함
- 현행 2026년 규정에 따라 노동절·제헌절도 공휴일에 포함
- 대체공휴일 규칙을 반영
- 임시공휴일/선거일처럼 정부가 수시 지정하는 날은 자동 달력에 없을 수 있으므로 수동 END 선택 가능

UI
- AUTO 선택 시 '광복절 → 휴일 시간표', '광복절 대체공휴일 → 휴일 시간표'처럼 판정 근거 표시
- 급행열차는 열차번호 옆에 눈에 띄는 '급행' 배지 표시
- 시발역 출발대기/조발 관련 기존 지연 표시는 변경하지 않음


Vercel 배포판
- 직접 ThreadingHTTPServer를 실행하지 않음
- server.py의 FastAPI app을 Vercel Python Function으로 실행
- 계산 코드는 engine.py
- SEOUL_API_KEY는 Vercel Environment Variable로만 주입


## V11 Vercel KST 수정
Vercel 런타임은 기본 UTC이므로 Python의 `datetime.now()`를 직접 사용하면
서울시 시간표/실시간 API(KST)와 9시간 차이가 발생합니다.

V11부터 모든 운행 계산의 현재시각을 `Asia/Seoul`로 고정합니다.
- 실시간 열차 후보 판정
- API 데이터 freshness
- AUTO 공휴일 판정
- 라이브 추적
- 승차 가능시간 계산

프론트엔드의 사용자 입력시각도 한국시간 기준으로 동일한 시간축에서 비교됩니다.


## V11 UI 개선
- 열차 후보/선택 열차에 실제 운행 시발역 → 종착역 표시
- 일반열차 / 급행열차 구분을 텍스트로 명확히 표시
- 급행 배지는 기존처럼 유지
- 역 입력창 클릭만으로 전체 역 목록을 표시하지 않음

- 초성 검색 지원
  · `ㅅ` → 초성이 ㅅ으로 시작하는 역
  · `ㅅㄱ` → 초성이 ㅅㄱ으로 시작하는 역
  · `성` → '성'으로 시작하는 역
- 최대 8개 후보 표시, ↑/↓/Enter/Esc 키보드 조작 지원


## V11 — 자동 지하철 길찾기
- 출발역/도착역만 입력하면 지원 노선 전체에서 빠른 경로 자동 탐색
- 공식 열차별 시간표에서 생성한 station-line 그래프를 Dijkstra로 탐색
- 비용 = 시간표 기반 차내 주행시간 + 환승 기본 4분
- 자동 생성 경로를 기존 구간 편집기에 바로 채움
- 이후 기존 realtimePosition ETA 엔진으로 즉시 재계산
- 자동 경로 생성 후에도 노선/역/환승시간을 사용자가 직접 수정 가능
- 초성 검색 지원
- 현재 지원: 1~9호선, 경의중앙선, 수인분당선

예:
마포구청 → 성균관대
6호선 마포구청→합정
2호선 합정→신도림
1호선 신도림→성균관대

주의:
- V11 자동 경로 탐색 자체는 번들된 공식 시간표 그래프 기준
- 이후 실제 도착시간은 실시간 열차 위치/지연으로 별도 재계산
- 같은 이름이지만 서로 다른 역인 5호선 양평 / 경의중앙선 양평은 환승 연결에서 제외
