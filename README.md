# 지금타 V14.3

출시 준비용 정리 버전입니다. V14.2까지 누적된 중복 폴더, 과거 버전 문서, 원본 변환 산출물과 감사용 중간 파일을 배포 트리에서 제거했습니다.

## 현재 지원
- 실시간 + 시간표: 1~9호선, 코레일 계열 지원 노선, 신분당선, 신림선, 우이신설선, GTX-A
- 시간표 전용: 인천1호선, 인천2호선, 김포골드라인, 의정부경전철, 용인경전철
- GTX-A는 북측(서울역~운정중앙)과 남측(수서~동탄)을 단절 구간으로 유지합니다.
- 인천2호선 `서해구청`은 별도 제공된 역 시각표의 실제 도착/출발 시각을 사용합니다.

## 실행
로컬: `python app.py`

Vercel: 기존과 같이 `server.py` FastAPI 엔트리포인트를 사용합니다. `SEOUL_API_KEY` 환경변수가 필요합니다.

Redis/DB를 아직 연결하지 않은 경우 기본 realtime store 모드는 기존 direct 방식으로 동작합니다.

## 폴더 정책
루트에는 현재 실행에 필요한 코드/데이터만 둡니다. 과거 버전별 CHANGELOG/AUDIT, 원본 XLS/XLSX/CSV, import 중간 산출물은 배포본에 넣지 않습니다.

- `tests/`: 현재 기능 회귀 테스트만 유지
- `tools/`: 현재도 사용할 관리 도구만 유지
- 시간표 원본과 과거 감사자료는 별도 보관하고 실행 프로젝트에는 복사하지 않음
