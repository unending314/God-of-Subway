# 지금타 V14.9.8

## V14.9.8 2호선 후보 방향 / 실시간 매칭 보강

- 2호선 `직전 열차`와 다른 열차 후보는 추천 열차와 같은 내선/외선 방향만 표시합니다.
- `앞 열차를 탄 것 같아요`를 `다른 열차를 탄 것 같아요`로 바꾸고 누르면 다른 열차 후보 목록을 펼칩니다.
- 후보 목록 제목을 `다른 열차 후보 N개`로 변경하고 요약의 `미포착 열차 포함` 문구를 제거했습니다. 개별 후보의 `미포착` 상태 표시는 유지합니다.
- 후보 출발/도착 시각을 더 크게, 파란 계열로 강조했습니다.
- 2호선 실시간 API 열번이 시간표와 직접 매칭되지 않을 때 `내/외선 + 현재역 + 관측시각`으로 보수적 문맥 복구를 시도합니다. API 행 자체가 없으면 시간표 예상 소재로 강등됩니다.

## V14.9.7 결과 UI 정리

- 대안경로는 기본 접힘 상태이며 `경로 직접 선택` 버튼형 summary로 노출됩니다.
- 결과 요약 중복 문구를 제거하고 총 소요시간·최종 도착 예정만 가볍게 강조합니다.
- 모바일 재검색 로딩 버튼 크기와 열차 추적 긴 역명 레이아웃을 보정했습니다.


## V14.9.6 빠른환승 방향 정규화

빠른환승 위치는 시간표의 실제 운행방향을 기준으로 매칭합니다. 급행 통과, 종착역, 일방통행 순환구간 때문에 방향키가 달라지는 경우에도 기존 위치 데이터를 재사용합니다. 현재 시간표 기준 실제 미보유 위치는 6개 방향 조합만 남아 있습니다.

## V14.9 입력 화면 정리

`God-of-Subway-dev-ts-bun`에서 초기 경로 입력 화면만 이식했습니다. 엔진 및 결과 화면은 V14.8 기능을 그대로 유지합니다.

## V14.8 1호선 계획 추월 반영

- 공식 1호선 시간표에서 `완행이 대피역에 정차하는 동안 뒤따르던 급행이 통과하고 이후 순서가 뒤집히는` 관계를 자동 검출합니다.
- 평일 59건 / 휴일 48건의 고신뢰 계획 추월 관계를 `route_graph.json`에 사전 계산해 저장합니다.
- 실시간 열차별 지연이 서로 달라도, 추월역 이후 ETA에서는 예정된 급행 우선 운행순서를 보존합니다.
- 현재 실시간 지연값은 그대로 표시하고, 추가 대피가 필요한 경우 `군포에서 K1951 급행 추월 대기 예상 · 1분 30초 추가 대기 반영`처럼 별도 운행정보를 표시합니다.
- 추월역 전에 내리는 승객에게는 이 보정을 적용하지 않습니다.
- 급행 지연이 지나치게 커 계획운전 변경 가능성이 높은 경우(추가 대피 10분 초과)에는 ETA를 강제로 묶지 않고 `운전정리 변동 가능`을 표시합니다.

## V14.7 경로 선택 / 공유구간 환승

- 자동 길찾기에서 서버가 비교한 추천 경로와 상위 대안 경로를 사용자가 직접 선택할 수 있습니다.
- 상단 상태 영역의 버전은 서버 `/api/health` 값으로 표시합니다.
- 4호선↔수인분당선 및 서해선↔경의중앙선의 공유선로 구간은 같은 진행방향일 때 환승 보행시간 0초로 처리합니다. 다음 열차 대기시간은 그대로 계산합니다.
- 금정역 1호선↔4호선은 기존 64초의 짧은 환승시간을 유지합니다.

V14.4 공개데이터 보강본에 사용자 완성 환승 CSV를 반영한 출시 준비 버전입니다.

## 현재 지원
- 실시간 + 시간표: 1~9호선, 코레일 계열 지원 노선, 신분당선, 신림선, 우이신설선, GTX-A
- 시간표 전용: 인천1호선, 인천2호선, 김포골드라인, 의정부경전철, 용인경전철
- GTX-A는 북측(서울역~운정중앙)과 남측(수서~동탄)을 단절 구간으로 유지합니다.
- 인천2호선 `서해구청`은 별도 제공된 역 시각표의 실제 도착/출발 시각을 사용합니다.

## V14.4 환승 위치 보강
- `국토교통부_철도역 빠른 환승 정보_20250923`을 현재 시간표 방향과 대조해, 기존에 위치가 없던 환승 관계만 보강합니다.
- 기존 검증/사용자 제공 환승 위치는 덮어쓰지 않습니다.
- 공개데이터에 환승시간 컬럼이 없으므로 새로 추가된 관계의 시간은 180초 fallback을 유지합니다.
- 방향 조합이 모호하거나 동일 방향에 서로 다른 위치가 충돌하는 행은 자동 반영하지 않습니다.
- 신규 공개데이터 레코드는 `direction_strict=true`로 저장되어, 공개되지 않은 반대 방향으로 빠른환승 위치가 잘못 전파되지 않습니다.


## V14.6 총신대입구(이수) 방향별 환승시간

총신대입구(이수) 4호선↔7호선은 8개 방향 조합별 실제 환승시간을 사용합니다. 자동 경로 탐색의 방향 미확정 단계에서는 230초를 보수적 대표값으로 쓰고, 경로 확정 후 190/230초의 실제 방향별 값으로 재계산합니다.

## V14.5 환승정보 완성 반영
- 사용자 입력 빠른환승 위치 132개 방향 조합을 모두 `transfer_data.json`에 반영했습니다.
- 사용자 입력 환승시간 103개 방향을 모두 반영했습니다.
- 신규 노선 환승 위치를 대폭 보강했으며, V14.9.7의 실제 방향 감사 기준으로 사용자 보강값까지 반영해 현재 감사 대상 6개 방향 조합의 빠른환승 위치도 모두 확보했습니다.
- 인천시청 인천1호선 → 인천2호선은 기본 260초이며, 인천1호선 하행(예술회관 방향)에서 갈아타는 경우만 130초입니다.
- 사용자 입력 원본 CSV와 audit 산출물은 실행 프로젝트에 넣지 않고 별도 보관합니다.

## 실행
로컬: `python app.py`

Vercel: 기존과 같이 `server.py` FastAPI 엔트리포인트를 사용합니다. `SEOUL_API_KEY` 환경변수가 필요합니다.

Redis/DB를 아직 연결하지 않은 경우 기본 realtime store 모드는 기존 direct 방식으로 동작합니다.
